# DukaFlow AI System Architecture

## Planned services

1. React and TypeScript frontend
2. Java Spring Boot REST API
3. MySQL relational database
4. Python FastAPI AI service
5. M-Pesa Daraja sandbox integration
6. Cloud deployment and CI/CD services

## Initial request flow

```text
Browser
   |
   v
React frontend
   |
   v
Spring Boot API -----> MySQL
   |
   +-----------------> FastAPI AI service
   |
   +-----------------> M-Pesa Daraja sandbox
```

Detailed component, deployment and security diagrams will be added before implementation.
