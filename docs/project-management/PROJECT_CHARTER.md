# DukaFlow AI Project Charter

## Project description

DukaFlow AI is an AI-powered retail ERP platform designed for small and medium-sized businesses in Kenya. It will centralize inventory, purchasing, sales, expenses, branch operations, payments and analytics.

## Objectives

- Provide secure authentication and role-based authorization.
- Support multiple businesses and branches.
- Manage products, categories and inventory movements.
- Record supplier purchases and customer sales.
- Track expenses and business performance.
- Integrate the M-Pesa Daraja sandbox.
- Forecast product demand through a Python AI service.
- Maintain auditable records of important system activities.
- Demonstrate testing, containerization and continuous integration.

## Initial release scope

- Authentication
- Roles and permissions
- Business and branch management
- Products and categories
- Inventory and stock movements
- Suppliers and purchases
- Customers and sales
- Expenses
- Basic analytics
- Audit logs

M-Pesa and AI functionality will follow after the core retail workflow is stable.

## Out of scope for the first release

- Full accounting general ledger
- Payroll
- Native mobile applications
- Production eTIMS integration
- Real-money M-Pesa processing
- International taxation

## Collaboration principles

Contributors will:

- Work through assigned GitHub issues.
- Create a branch for each feature or fix.
- Use pull requests and peer review.
- Test their changes.
- Document configuration and behavior.
- Keep credentials out of Git.
- Credit each contributor accurately.
- Communicate blockers early.

## Portfolio use

Both contributors may present DukaFlow AI in their CVs, portfolios and interviews. Each contributor must accurately describe their own responsibilities and must not claim sole authorship.

## Success criteria

The first stable release must support secure sign-in, role-based access, products, stock, purchases, sales, expenses, dashboards, automated tests, Docker-based local execution, deployment and complete project documentation.
